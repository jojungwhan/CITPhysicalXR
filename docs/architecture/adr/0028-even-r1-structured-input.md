# ADR 0028: Even R1 is a separate structured input node

## Status

Accepted

## Context

Even R1 is paired and transported through the Even phone application and G2,
but it has different capabilities and a different safety role from the glasses.
The Even Hub SDK identifies system events from the ring separately from system
events generated by the glasses. Treating both as one node would hide the
source, make lesson assignment ambiguous, and risk preserving the old
device-to-device coupling pattern.

## Decision

Agent Mesh keeps the existing G2 implementation and adds an append-only,
acknowledged feed of semantic R1 gestures: tap, double-tap, scroll up, and scroll
down. Raw Bluetooth packets do not enter the Interaction Fabric. The Agent Mesh
adapter advertises R1 as an input-only `even-realities-r1` node that publishes
`interaction.gesture.smart_ring`.

The ring node is paired with a G2 parent for transport, but has its own stable
Fabric node ID, health, last-seen time, capability advertisement, catalog card,
image, discovery instructions, role assignment, and reconnect action. An old
Agent Mesh Hub that does not yet implement the interaction feed is treated as an
empty feed so the existing G2 and coding-agent bridge continues to work.

The `smart-ring-device-control` course interprets scroll up/down as short,
bounded forward/backward velocity cues and tap as a zero-velocity cue. Each
assigned ground adapter still applies its local deadman stop and device bounds.
Double-tap can propose only the high-level
`mobility.flight.fleet_sequence.start` action, and only to a separately assigned
fleet controller. It remains rejected unless the session is active, the target
is connected and armed, instructor override is clear, and the Tello one-shot
checklist is valid.

R1 input never becomes a coding-agent prompt and never passes through an LLM.
No ring event can emit arbitrary shell, robot, or flight commands.

## Consequences

- Tutors can assign R1 independently from G2 while reusing the working Even
  transport and mobile integration.
- RoboMaster, Sphero, mobile LEGO hubs, Dash, and future compatible ground nodes
  require no ring-specific adapter code.
- The same structured ring event can fan out to several assigned outputs, with a
  distinct command lifecycle and safety decision for every target.
- R1 must still be paired to G2 in the Even app before CIT can observe it; local
  Windows discovery cannot replace that vendor-defined Bluetooth pairing step.
- Semantic interaction rows expire after 24 hours, while only minimal companion
  last-seen state is retained for remembered reconnection.
